# 33250A整合操作說明

這份文件說明目前軟體裡 `33250A` 的整合方式，以及怎麼和 `MCU`、`示波器` 一起使用。

## 支援的連線模式

目前 `33250A` 支援兩種模式：

- `visa`
- `serial`

相關手冊：

- [33250A.pdf](C:/Users/winston_YEH/Documents/25230/CODE/艾科/docs/instruments/33250A.pdf:1)

## GUI 操作

1. 開啟 `Pulse Bench Console`
2. 切到 `33250A` 分頁
3. 選擇連線模式
4. 依模式填入：
   - `VISA Resource`
   - 或 `Serial Port / Baudrate`
5. 按 `連接 33250A`
6. 按 `Identify`

常用欄位：

- `波形`
  - `SIN / SQU / RAMP / PULS / NOIS / DC`
- `頻率 (Hz)`
- `振幅 (Vpp)`
- `Offset (V)`
- `Trigger Source`
  - `IMM / EXT / BUS`

常用按鈕：

- `套用波形`
- `Output ON`
- `Output OFF`
- `送出 Trigger`
- `讀取錯誤`
- `列出 VISA 裝置`
- `重新掃描 COM`

## CLI 操作

列出 VISA resource：

```powershell
python -m host.src.pulse_host.cli gen-list-resources
```

讀取機器資訊：

```powershell
python -m host.src.pulse_host.cli gen-identify --gen-mode visa --gen-resource "USB0::..."
```

套用波形：

```powershell
python -m host.src.pulse_host.cli gen-apply ^
  --gen-mode visa ^
  --gen-resource "USB0::..." ^
  --gen-function PULS ^
  --gen-frequency 1000 ^
  --gen-amplitude 5 ^
  --gen-offset 0 ^
  --gen-trigger-source IMM
```

開啟輸出：

```powershell
python -m host.src.pulse_host.cli gen-output-on --gen-mode visa --gen-resource "USB0::..."
```

關閉輸出：

```powershell
python -m host.src.pulse_host.cli gen-output-off --gen-mode visa --gen-resource "USB0::..."
```

手動觸發：

```powershell
python -m host.src.pulse_host.cli gen-trigger --gen-mode visa --gen-resource "USB0::..."
```

讀取錯誤：

```powershell
python -m host.src.pulse_host.cli gen-error --gen-mode visa --gen-resource "USB0::..."
```

## 建議整合順序

如果之後要把 `33250A + MCU + 示波器` 全部串起來，建議順序：

1. 先連 `MCU`
2. 確認 `PING / STATUS`
3. 再連 `示波器`
4. 確認 `Identify`
5. 再連 `33250A`
6. 用 `Identify` 確認 33250A 已連上
7. 先 `套用波形`
8. 再 `Output ON`
9. 最後才開始做 trigger / pulse / 截圖流程

## 注意

- `serial` 模式需要正確的 COM port 與 baudrate
- `visa` 模式需要系統已安裝 VISA backend
- 如果只是先驗證 33250A 連線，建議先用：
  - `Identify`
  - `套用波形`
  - `Output ON / OFF`
- 等訊號鏈全部接好，再做和示波器、MCU 的聯動
