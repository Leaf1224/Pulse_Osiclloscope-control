# Documentation Index

## 中文說明

這個資料夾專門放文件，不放實作程式。目的是讓需求、參考資料與實際程式碼分開管理，避免根目錄越用越亂。

This workspace keeps requirements and reference material separate from implementation.

## Structure

### 中文說明

`context/` 放產品需求與 FW/SW 背景，`instruments/` 放儀器手冊或程控文件，而 `docs/` 根目錄則放這個專案自己的工程筆記。

- `context/`
  - product requirements and FW/SW context documents
- `instruments/`
  - external instrument manuals and programming references
- root of `docs/`
  - short engineering notes specific to this repository
